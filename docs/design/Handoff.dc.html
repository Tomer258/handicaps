Accessibility baseline
All text ≥ 4.5:1 on its surface (tx-3 #868D99 on bg-2 = 4.9:1). Speaking, muted and live are never color-only: ring + icon + aria-label. Focus-visible ring on every control. Live regions announce “Maya started streaming” and sound plays (rate-limited).
Keyboard
Ctrl+Shift+M mute
Ctrl+Shift+D deafen
Ctrl+K search / jump
Alt+↑ / ↓ prev / next channel
Alt+1…9 favorite sounds
Esc close top overlay
Tab-focused only — no global OS hotkeys from a website.
Motion & performance
Speaking ring toggles a class (no layout). Waveforms run only on the playing tile. Stream tiles use CSS aspect-ratio and object-fit for Fit / Fill. Honor prefers-reduced-motion and the in-app toggle via a root [data-reduce-motion] attribute.
